## Agent guidance

The agent contracts in this directory define bounded roles for archive inspection,
metadata intake, materialization, library ingest, and Mylar handoff. The skills
under `../../skills/comics/` provide reusable operating instructions.

## Separation rule

Comicbox, Codex, Mylar, Kavita, Komga, and Calibre documentation may describe
external applications, but their deployment files and host-specific operations do
not belong in this comic-tools bundle. Calibre material remains in its own tool
and documentation area.
